# GD Shader Script

This is a Godot editor plugin that enables users to write their shaders with GDSS - a GDScript-style shading language.

For the grammar of GDSS, see [Grammar](./grammar_table.md).

This plugin allows you:
- Import *.gdss files into Godot file system as `Shader`;
- Translate *.gdss files to *.gdshader files.
